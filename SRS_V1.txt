## 1. Introduction

### 1.1 Purpose

The **Sentiment-to-Price Correlation Analyzer** is a data-driven software system designed to analyze the relationship between financial news sentiment and subsequent stock price movements. The system employs **Natural Language Processing (NLP)** via **FinBERT** to extract sentiment from news headlines and **machine learning** via **XGBoost** to predict next-day price direction.

### 1.2 Scope

The system provides:

1. **Real-time news fetching** for NSE (National Stock Exchange of India) stocks
2. **Sentiment analysis** using FinBERT (a BERT model fine-tuned on financial texts)
3. **Statistical correlation analysis** between sentiment and price returns
4. **Predictive modeling** using XGBoost with baseline comparisons
5. **Interactive visualization** via a Streamlit dashboard

### 1.3 Objectives

| **Objective** | **Description** |
|---------------|-----------------|
| **O1** | Extract and process financial news for 20+ NSE stocks |
| **O2** | Generate sentiment scores using FinBERT with high confidence |
| **O3** | Compute Pearson correlation with statistical significance (p-values) |
| **O4** | Build XGBoost classifier with accuracy > 50% (beating random baseline) |
| **O5** | Provide interactive dashboard for real-time analysis |
| **O6** | Generate comprehensive reports (PDF/Markdown) |

### 1.4 Stakeholders

| **Stakeholder** | **Role** |
|-----------------|----------|
| **Student Developer** | System designer and implementer |
| **College Faculty** | Project evaluator and mentor |
| **End Users** | Investors, analysts, and researchers |
| **Future Researchers** | Extension and enhancement of the system |

## 8. Problem Solving & Solutions

### 8.1 Key Problems Encountered & Solutions

| **Problem** | **Root Cause** | **Solution** | **Status** |
|-------------|----------------|--------------|------------|
| **P1**: `ModuleNotFoundError: statsmodels` | Plotly's `trendline='ols'` requires statsmodels | Installed `pip install statsmodels` | ✅ Solved |
| **P2**: `use_column_width` error | Streamlit 1.36.0+ deprecated the parameter | Changed to `use_container_width=True` | ✅ Solved |
| **P3**: Data not updating (cached) | Streamlit's `@st.cache_data` caching stale data | Added TTL=300s and refresh button | ✅ Solved |
| **P4**: Groww API unavailable | Library not on PyPI or API changed | Fallback to Google News RSS + synthetic data | ✅ Solved |
| **P5**: FinBERT model download slow | Large model (~1GB) | Added progress bar; use cached model | ✅ Solved |
| **P6**: Memory errors with large datasets | Processing all stocks at once | Process stocks in batches | ✅ Solved |

### 8.2 Problem-Solution Details

#### Problem 1: statsmodels Not Installed

```python
# ❌ Error
import statsmodels.api as sm
# ModuleNotFoundError: No module named 'statsmodels'

# ✅ Solution
pip install statsmodels
```

**Impact**: Without statsmodels, the scatter plot trendline wouldn't render.

#### Problem 2: Streamlit Parameter Change

```python
# ❌ Old (causes error in Streamlit 1.36.0+)
st.image("image.png", use_column_width=True)

# ✅ New (works in all versions)
st.image("image.png", use_container_width=True)
```

**Impact**: Breaking change in Streamlit 1.36.0. Fixed by updating all occurrences.

#### Problem 3: Cache Not Refreshing

```python
# ❌ Old (caches forever)
@st.cache_data
def fetch_data():
    return yf.download(...)

# ✅ New (auto-refreshes after 5 minutes)
@st.cache_data(ttl=300)
def fetch_data():
    return yf.download(...)
```

**Impact**: Added "Refresh Data Pipeline" button for manual refresh.

#### Problem 4: Data Fetching Failures

```python
# ✅ Solution: Multi-tier fallback
def fetch_news(tickers):
    try:
        # Tier 1: Groww API
        return fetch_from_groww(tickers)
    except ImportError:
        try:
            # Tier 2: Google News RSS
            return fetch_from_rss(tickers)
        except:
            # Tier 3: Synthetic data
            return generate_synthetic_data(tickers)
```

**Impact**: System remains functional even when APIs fail.
